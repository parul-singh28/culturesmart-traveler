**CultureSmart Traveler** helps travelers navigate social norms, avoid cultural faux pas, master local etiquette, practice pronunciation with native audio speech synthesis, and explore cities worldwide with confidence.

---

## ✨ Features

- 🏙️ **Comprehensive City Profiles**: Deep cultural guides for 10 world-class destinations:
  - **Tokyo, Japan** 🇯🇵 (*Omotenashi*, quiet subways, tipping taboos, chopstick manners)
  - **Paris, France** 🇫🇷 (The *Bonjour* imperative, *art de vivre*, dining pacing, quiet public volume)
  - **Rome, Italy** 🇮🇹 (Bar counter espresso rituals, church dress modesty, *coperto* vs tipping)
  - **Bangkok, Thailand** 🇹🇭 (The *Wai* greeting, sacred head vs feet rules, royal reverence, tuk-tuk scam avoidance)
  - **Marrakech, Morocco** 🇲🇦 (Right-hand dining, mint tea hospitality, Medina modesty, friendly bargaining)
  - **Mexico City, Mexico** 🇲🇽 (*¡Buen provecho!* dining courtesy, *la propina* 10–15%, street taco customs)
  - **Seoul, South Korea** 🇰🇷 (Two-handed respect, drinking etiquette, subway priority seats, *Jeong*)
  - **Dubai, UAE** 🇦🇪 (Public decorum, Ramadan etiquette, right-hand coffee acceptance, civility laws)
  - **London, United Kingdom** 🇬🇧 (Sacred queueing, right side of Tube escalators, pub bar ordering)
  - **New York City, United States** 🇺🇸 (Sidewalk pace, 20% tipping scale, empty subway car avoidance)

- 🚦 **Color-Coded Dos & Don'ts**:
  - Emerald green badges for positive etiquette (**DO**) and rose red badges for cultural taboos (**DON'T**).
  - Filterable by **Tipping, Dining, Dress Codes, Gestures, Social Norms, and Safety/Scams**.
  - **Cultural Context**: Explains the underlying *why* and philosophical reasoning behind every custom.

- 🗣️ **Interactive Quick Phrasebook with Native Audio**:
  - Native scripts (Kanji, Arabic, Hangul, Thai), romanized phonetic pronunciations, and English meanings.
  - Native **Web Speech API** audio playback with voice matching and speed controls (**0.7x Slow** for learners, **1.0x Normal**).

- 🚇 **Transit & Commuter Etiquette Guide**:
  - Escalator walking/standing lanes, quiet zones, backpack positioning, taxi automatic doors, and recommended city transit apps.

- 🏛️ **Must-Visit Cultural Sights & Hidden Gems**:
  - Sacred sanctuaries and heritage landmarks with visiting hours, dress code rules, and insider tips.

- 🧠 **Culture IQ Etiquette Challenge**:
  - Gamified 8-question quiz testing global travel etiquette with instant answers and cultural lessons.

- ⚖️ **Side-by-Side City Comparison Tool**:
  - Compare behavioral norms (Tipping, Dining, Greetings, Transit) directly between any two global cities.

- 💬 **Traveler Stories & Cultural Saves**:
  - Community tips and firsthand mishap lessons with live submission saved to `localStorage`.

- 🖨️ **Offline Pocket Guide (Print / PDF)**:
  - Custom print stylesheet that transforms any city profile into a clean, pocket-foldable physical or PDF cheat sheet.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/parul-singh28/culturesmart-traveler.git

# Navigate to project directory
cd culturesmart-traveler

# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:3000` or `http://localhost:5173` in your browser.

### Building for Production
```bash
npm run build
npm run preview
```
